## 🧱 ¿Qué es Databricks?

**Databricks** es una **plataforma de datos y analítica** basada en **Apache Spark**, diseñada para:
- Big Data
- Data Engineering
- Machine Learning / IA
- Analytics y BI
Su idea principal es unificar en un solo lugar:  
👉 **datos + procesamiento + modelos de IA**

## 🤖 ¿Databricks sirve para IA?

**Sí, totalmente.**  
De hecho es uno de sus casos de uso principales.

Con Databricks puedes:

- Preparar y limpiar datos (ETL/ELT)
- Entrenar modelos de ML y Deep Learning
- Usar **MLflow** para tracking de modelos
- Hacer **Feature Engineering**
- Desplegar modelos
- Trabajar con notebooks (Python, SQL, Scala, R)

Se usa mucho para:

- Recomendadores
- Predicción (forecasting)
- Detección de fraude
- NLP
- Computer Vision
